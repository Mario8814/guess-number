# 猜数字游戏

一个简单的命令行猜数字小游戏,我的第一个 GitHub 项目。

## 玩法

程序会随机想一个 1 到 100 之间的数字,你不断输入数字来猜,程序会提示"太大了"或"太小了",直到你猜对为止。猜对或次数用完后,可以选择要不要再来一局。

## 怎么运行

需要电脑上装有 Python 3。

```bash
python guess_number.py
```

## 示例

```
欢迎来玩猜数字游戏!
我已经想好了一个 1 到 100 之间的数字,你来猜猜看。
请输入你猜的数字: 50
太小了,再大一点!
请输入你猜的数字: 75
太大了,再小一点!
请输入你猜的数字: 63
恭喜!你猜对了,就是 63!
你一共猜了 3 次。
```
